# MUSIC CRAFT

Sitio estático. Abrí index.html para probar la portada, SHOP y WORKSHOP.

## Publicar en GitHub Pages

1. Descomprimí el paquete y subí su contenido a la raíz de la rama main del repositorio. Incluí assets y el archivo oculto .nojekyll.
2. En Settings → Pages → Build and deployment, elegí Deploy from a branch.
3. Seleccioná main y /(root), y guardá.
4. Cuando termine la publicación, abrí la dirección que indica GitHub Pages. Probá SHOP, WORKSHOP y la franja VOLVER en cada sección.

Los recursos usan rutas relativas para funcionar también bajo la ruta del repositorio. No requiere dependencias ni compilación.
